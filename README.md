# FloodAlert Salone
A community flood early-warning system for Freetown, Sierra Leone.
PROG101 Principles of Programming Logic and Design - Assignment 1
Student: Owen Carew | ID: 905006535 | Lecturer: Elijah Fullah

## Problem
Flash floods hit communities such as Kroo Bay, Culvert and Mabella
every rainy season, and residents get little or no warning.

## Solution
Volunteers enter rainfall (mm) and drain/river level (m). The system
calculates a risk level (GREEN, YELLOW, ORANGE, RED) and sends SMS
alerts with safety instructions to registered residents.
